# PinjemDulu

Aplikasi peminjaman inventaris antar-OKI Polinema. Peminjam mengajukan peminjaman secara online, lalu Penanggung Jawab Inventaris mengelola barang dan peminjaman di OKI-nya.

## Struktur repo

- `FE/`: frontend HTML, CSS, dan JavaScript. Lihat FE/README.md.
- `BE/`: backend, belum disiapkan.

## Menjalankan frontend

```bash
cd FE
npm ci
npm test
```

Lalu buka FE/index.html dengan Live Server. Modul ES tidak jalan lewat file://.
